# Dark 主题的 Mariana 配色

LazyClash 的默认主题为 Dark。它以 Mariana 的正文配色和 Adaptive 的界面层次为参考，适配终端字符单元。设置页还可选择 Light 或 Auto。操作方式见[设置页](settings.md#布局与交互)。

## 换算规则

A：原资源直接提供的不透明颜色，HSL 到 RGB 仅转换表示方式。B：按原资源运算或透明度合成得到的不透明色。C：为终端用途、对比度或统一状态所作的明确适配。

HSL 使用标准 sRGB HSL 转换。中间步骤保留浮点精度，最终 0–255 通道四舍五入，恰好半值向上。例如 `hsl(210, 60%, 70%)` 绿色通道为 178.5，取 179。色值可能因此与提前取整的网络色板差一个通道单位。

`color(base blend(other p%))` 在未指定色彩空间时使用 RGB：`result = p × base + (1-p) × other`，这里 p 是保留 **base** 的比例。它与“不透明度 p 的 other 覆盖 base”含义相反。透明覆盖使用 `result = alpha × foreground + (1-alpha) × background`；若 layer 另有 opacity，则乘入 alpha。终端输出全部为不透明颜色，无真实透明遮罩。

Mariana 的背景变量 `blue3 = hsl(210, 15%, 22%)` 未取整 RGB 为 `(47.685, 56.1, 64.515)`。其 HSV V 为 0.253，因此根据 Sublime 文档属于 `file_medium_dark`；Adaptive 的 sidebar 和 quick_panel 使用 `medium_dark_bg`。

列表和集合面板没有内容时，空态文案及必要操作在剩余内容区水平、垂直居中，页头、搜索、筛选和底部状态行保留原位。区分暂无数据、筛选无结果、内核停止与读取失败；加载、未安装及启动中的状态也保留准确说明。读取失败优先于空结果，保留诊断并只提供当前页支持的恢复动作；筛选无结果可清除筛选，内核停止可启动，未安装可进入安装。已有记录仍按原列表展示，不因断线或内核停止清空；订阅页只列用户添加的配置，空库提示在导入工具栏下方居中。矮屏压缩补充说明以保留状态与操作，按钮的鼠标区域跟随居中位置，工具栏和空态不重复使用同一键盘停靠点。

常驻侧栏的静态字标为连续的九个字母 `lazyClash`，在整栏 20 个字符格内居中，左侧留六格，右侧留五格。字标加粗，使用 Lip Gloss 的 CIELAB 一维混色，从月光蓝 `#8fc9ef` 渐变到薰衣草紫 `#c4a7e7`。窄窗口的页头有空间时也显示此字标，向导等静态界面使用同一拼写。常驻侧栏 Logo 区使用 `sidebarBackground` 深色背景，右侧标题区及窄窗口 Menu 按钮周围使用与正文一致的 `bg`，常驻侧栏保留独立深色背景。页面标题使用近白色 `pageTitleForeground` 加粗，前置 `pageTitleMarker` 灰蓝色短竖线 `▎` 与一格间距；无色模式仍保留短竖线。右侧状态统一使用次要文字色 `muted`，操作按钮保留自身状态样式。Logo 与标题共用高度与文字基线，上下留白对称：终端至少 24 行时顶栏为 3 行，上下各留 1 行，更矮窗口使用紧凑顶栏并按需保留操作行。常驻侧栏的第一项紧接 Logo 区底边。右侧正文紧接三行顶栏，使用紧凑顶栏时在正文前留一行。弹出菜单保留内部滚动提示区，不覆盖顶栏。

各页常驻侧栏底部采用相同的居中布局。高度允许时，菜单与状态区之间用空行分隔。状态行直接显示「● 运行中」等简短文字，符号携带状态色，无色终端保留符号和文字。能确认当前进程的启动时间时，在状态正上方用加粗的正文色居中显示运行时长 `HH:MM:SS`。空间紧张时收为一行状态，侧栏折叠时改由页头显示状态。上下行速率在概览的实时流量卡中显示。

侧栏收起时，各页标题旁显示内核状态，隐藏快捷键底栏后仍保留。页面动作优先占据原有位置，标题区依次去掉重复 Logo、压缩状态文字；不足 40 列仅保留状态标记。低色和无色模式使用 `ON`、`OFF`、`WAIT`、`ERR`、`N/A` 或 `?`，不依赖颜色判断运行、停止、进行中、失败、未安装或未知状态。正在提交的启停操作优先显示过渡状态，实际状态仍由服务观测确认。

实际终端尺寸、色彩能力与初始状态就绪约 200 ms 后，常驻侧栏播放一次约 1 秒的进场动画。字母 `z` 变为 💤，停留约 0.4 秒后恢复为 `z`。渐变两端平滑提亮至 `#c5efff` 和 `#ead7ff`，再恢复原色。初始侧栏不可见、加载失败、界面被遮挡或终端低于 256 色时跳过本次进场。等待或播放期间切页、缩放或打开弹窗会结束本次动画，点击字标则立即播放点击彩蛋。

点击彩蛋持续约 1.6 秒。字母 `z` 先变成暖色 `focus` 的 `!!`，再回到常态渐变，依次发呆（`..`）、打盹、睡着（💤），最后恢复完整的 `lazyClash`。当动画中的符号占两格时，`la` 向左借一格，左右各留五格。`yClash` 始终从侧栏第十格开始。终端至少 24 行时，两串梦泡在 💤 上方逐格向右移动。第一串沿用对应列的渐变色，第二串使用较淡的 `disabled`。更矮的窗口只播放字标行的变化。点击字标所在行的任意一格都可播放彩蛋，再次点击从头播放。Tab 导航跳过字标。忙碌、弹窗或侧栏隐藏时结束播放。

常驻侧栏宽 20 列，通过背景色差与正文分区，不绘制竖向分隔线。菜单标签本身居中，键盘焦点在标签前独立两列显示橙色 `› `，不参与标签居中计算。当前页整行使用正文底色 `bg`，与右侧内容区相连，菜单名加粗；普通彩色模式不再叠加圆点和下划线。未选中项悬停仅提亮文字，保留侧栏原底色。侧栏方向键同步切页，焦点进入正文后菜单仍显示当前页背景。宽度不足 115 列或高度不足 9 行时，常驻侧栏自动收起；出现侧栏后正文仍至少保留 90 列，概览不因拉宽而退回单列。导航焦点转到顶部菜单按钮，正文焦点保持原位，不自动打开遮挡正文的抽屉。用户明确打开的抽屉在紧凑布局内缩放时保持，恢复宽屏后归入常驻侧栏。窄窗口弹出菜单保留右边框、独立选区及悬停背景。低色和无色模式在标签后显示 `•` 区分当前页，圆点同样不参与居中；焦点、悬停、当前页及颜色能力变化均不移动标签。标签裁切始终预留两侧装饰空间；极窄弹出菜单可以裁掉装饰，但不越过边框。

菜单可用空间足以完整显示七个三行项时保留上下留白，否则切换为连续单行项，优先让全部页面入口同时可见。相邻点击区域连续，不设置项间或分组空行。极矮弹出菜单连七个单行项也容不下时，才通过独立的 Bubbles viewport 滚动，并在视口外显示上下溢出箭头。鼠标滚轮每次移动一个菜单项，不切页、不滚正文，状态刷新保留浏览位置；侧栏 ↑↓ / j/k / Home / End 同步切页，重新进入导航组、打开菜单与缩放窗口时自动显示当前项。Enter / → / l 进入上次有效内容位置，只移动焦点；Esc 逐层返回，普通内容和纵向列表也可用 ← / h 执行同层返回。横向控件优先使用自身方向键，Profiles 网格内的 ← / h 保留卡片移动；输入、编辑、弹窗和菜单保留自身按键。常驻导航的 ← / h 不移动焦点，抽屉中的 ← / h 关闭抽屉。Shift+Tab 始终移到上一个控件。

底部提示栏默认显示。浏览页面时按 `?` 隐藏整栏，再按一次恢复。也可使用「设置 → 常规 → 底部提示栏」开关。下次启动沿用该选择。隐藏时包括退出提示在内的整行不占空间，正文、侧栏视口、溢出提示和鼠标区域同步释放一行，宽度断点和内容位置保持稳定。文本编辑期间 `?` 输入问号，结束编辑后即可切换提示栏。模态层保留各自的保存、取消或确认说明。

订阅卡片网格使用正文的可用宽度，与链接输入框左对齐。多列时每张卡片至少宽 48 格，列间留两格，最多四列。列数由窗口决定，末排缺少的卡片位置留空。同排卡片等高，相邻两排之间留一行。常规卡片在标题上方留一行，紧凑布局直接从标题开始。

标题行展示名称、更新和更多操作。下一行左侧优先展示用户填写的描述，留空时展示来源域名或文件类型。长描述截为一行，右侧留给距上次成功获取的时间。卡片左边缘的竖条标记已选配置，在无色终端也能辨认。额度行左侧用 `75 GiB / 100 GiB` 表示剩余量和总量，右侧显示服务商给出的到期日期（`YYYY-MM-DD`），到期时改为「已过期」。进度条按剩余比例填充，位于卡片最后一行，与正文共用左右边距。服务商未提供的数据留空。订阅设置面板标明「剩余」和「到期日期」，过期后也能查看具体日期。

概览按行展示七张卡片。第一排是「内核状态 / 当前订阅」，第二排是「网络设置 / 路由策略」，第三排是「网站测试 / IP 信息」，底部的「实时流量」占满整行。正文至少 90 列时，同排两卡等宽等高；高度不参与单双列切换，顶边和底边都对齐；奇数列剩余的一格留在卡片外侧，不分配给右卡。同排卡片按较高者的内容补齐。常规布局中，内核卡把补齐的空间放在正文与底部操作之间。窄屏按同一语义顺序单列并保留各卡所需高度。订阅和路由策略的跳页入口使用标题右侧的文本按钮，放不下时完整移至标题下一行；标题与正文之间仍留一行空白。未安装内核卡正文与安装操作之间留一行，排间留一行，左右卡之间留两列。宽屏右栏在路由策略与 IP 信息之间延续卡片底色，焦点轮廓仅包围当前分区。这些标题间距仅用于概览卡片。

「内核状态」卡的标题右侧使用文本入口「管理 ›」，正文首行显示 Mihomo。侧栏有空间显示秒表时，状态行靠卡片底部排列，上方留一行空白。靠左的状态文字「● 运行中」或「○ 已停止」可以直接切换。聚焦时显示 ›，无色终端还使用方括号标记可操作区域。启动、停止、故障和未知状态各有自己的文案。故障、版本不一致或监控异常的说明位于 Mihomo 与空行之间。

折叠侧栏或终端太矮时，Mihomo 下方直接显示状态行。可信的运行时长随即显示为「已运行不到 1 分钟」「已运行 1 小时 2 分钟」等，满一天后以天和小时显示，诊断信息紧随其后。标题行容不下管理入口时，入口完整移至下一行并保持右对齐。

七张普通概览卡片常态不绘制外边框，使用独立底色、内边距与间距分组；键盘浏览聚焦卡片时才绘制黄色细边框，进入按钮或返回导航后移除。始终预留同一圈字符格，焦点变化不移动内容、按钮或相邻卡片；无色终端同样保留焦点轮廓。首次安装引导保留边框。卡片的语义身份与几何区域由布局直接提供，宽窄切换保留焦点；PgUp/PgDn 翻页后，移出视口的内容焦点转到可见卡片。Enter 先进入卡片中的控件，之后显式激活才执行操作；没有操作控件的流量卡保持浏览焦点。

「路由策略」卡片的三个模式按钮等宽连排，整体居中。宽度足够时每段占八格，亮底粗字表示运行模式，橙色 › 表示键盘焦点。左右键在三段之间循环移动，Enter 或空格应用所聚焦的模式。内核停止或观测失败时显示已保存的模式。

按钮下方空一行，以「组名 → 成员」居中显示当前路径，嵌套组依次展开，末端节点加粗。窄屏从箭头前换行。规则模式有多个策略组时，点击组名或聚焦后按 Enter 可展开菜单。菜单只列组名，选择后收起并显示该组的路径。Esc 返回此前查看的组。只有一个组时直接显示路径。全局模式从 GLOBAL 展开，直连模式显示「所有流量直接连接。」

实时流量将细点阵 Braille 双曲线与六项数字整合为一张通栏卡，各尺寸均使用通栏曲线。时间轴下方的橙蓝方向标签同时充当图例，上传、下载各自配对显示当前速率和本次内核启动以来的累计量，第三组显示活跃连接和内核内存。每组内的数值按显示列对齐，宽度不足时整组换行。终端至少有 24 行时，三组并排的实时读数与次要读数之间留一行；分批排列时，同组两行相邻，相邻批次间留两行。较矮的窗口使用紧凑行距。上传和下载共享线性速率轴和最近 60 秒的时间窗口，使用 Braille 2×4 子点和单子点宽度的 Bresenham 连线，缺测或超过 3 秒的间隔保持断线。标准绘图区仍为六行，窄屏或短窗口四行，另有原来的一行时间标签，不使用终端图形协议。

数值、水平网格和刻度共用完整 Braille 子点坐标：`y = round((1 - rate / maximum) × (4h - 1))`，并把输入值和结果限制在有效范围。最大值在子点 0，零值在子点 `4h-1`，四舍五入带来的单点坐标误差不超过半个子点，等数值间隔的量化距离之差不超过一个子点。网格线在同一子点行用低对比度 `divider` 绘制；标签位于包含该子点的字符行 `y / 4`，极矮图优先端点标签。终端文本不能定位到字符行内任意高度，字体内四个点的距离和相邻字符行的留白也可能不同，因此不能保证偶数行图的三个文字标签在视觉上严格等距；这不改变数值坐标与曲线的线性关系。

零流量保持有效历史。每个方向独立跳过孤立零值点和两端均为零的线段，连续空闲时仅留下低对比度零基准线；非零下降到零及零上升到非零的过渡仍包含零端点，不把零转换成缺测，也不改变保存数据。无可见上传或下载点的字符格只绘制网格，避免空闲重合曲线被误认作第三条白线。 内核运行且正在等待首个流量样本时，图内显示「等待采样」。窗口内全部有效样本均为零、观测间隔不超过 3 秒且最新流量帧在 3 秒以内时，图内显示「暂无流量」。有曲线、已知缺测或流量源故障时，绘图区留给曲线和缺口。

上传曲线使用橙色 `#F9AE58`，下载曲线使用蓝色 `#7BAED0`。每个 Braille 字符显示两条曲线在该格内占用的全部子点。两条曲线共享一格时，各自计算占用的不同子点数，共用的子点在两边各计一次。整格取点数较多一方的颜色，平手取上传橙色。两条曲线完全重合时呈橙色，可从橙蓝方向标签旁的读数区分两个方向的实时速率。三个当前值均使用加粗正文色。低色终端复用既有调色板适配。无色终端保留全部曲线子点，顶部和中部参考线每四列画一格，零基准线每两列画一格。

量程由最近 60 秒有效上传、下载共同最大值决定，先加 15% 顶部空间再向上取友好刻度（含 1、1.25、1.5、2、2.5、3、4、5、6、8、10），取整后实际顶部留白可以更大；最小上限为 1 KiB/s。超出当前范围时立即扩容；较低目标量程不超过当前量程 60% 且连续有效观测满 10 秒后才收缩。窗口内峰值不会被忽略，缺测、超过三秒的间隔或恢复到阈值上方会重新开始低峰计时。该状态只随真实流量观测推进，缩放、重绘和查看其他页面不推进收缩时间，不改变实际速率或历史。

时间标签与样本共用同一 60 秒横轴，显示 `-60s`、`-30s`、`现在`；可用绘图区至少 56 列时增加 `-45s` 和 `-15s`，标签之间至少留一格。采样失败或相邻观测间隔超过 3 秒时，时间轴空位用 `┄` 标出缺测。刻度文字与相邻一格留白优先，有效观测也优先于同格缺测。出现可见标记时，标题行能容下图例时，在时间范围旁注明「┄ 缺测」。首个观测之前、最后一个观测之后的空白以及已观测到的零流量都不标记。

图表内部宽度至少 72 列时，纵轴预留 12 列。更窄时预留 10 列，只在顶部显示单位，例如从上到下为 `1.25MiB/s`、`0.625`、`0`。绘图区容不下 8 列时隐藏纵轴标签。底部用次要文字显示本次累计上传、下载和内核内存，字节数与单位在可用宽度内同行显示。来源不可用时仅该组对应数字为 `--`，真实零值显示零。已确认进程仍运行而监控不可用时，保留六项未知值，不复用旧指标或提示重新启动内核。累计量取内核计数，不积分速率或跨重启累加。历史按实际时间保留 60 秒且最多 128 点，不预填、不补采、不持久化；页面切换、缩放和弹窗继续复用共享会话，断流保留时间缺口，确认停止、卸载或实例变化后清理旧曲线。旧代、旧时间、重复和未来样本不能覆盖当前状态。

Original、Thick、Smooth 对比仅存在于测试二进制：Original 保留原 Bresenham；Thick 在同一子点列向下增加一个相邻子点，裁切在边界内，不向左右扩张或跨缺口；Smooth 在每个有效连续区间内使用保形 PCHIP，再以 Bresenham 栅格化，经过原采样点且不超出局部范围。三者共享同一测试数据、窗口、宽高、Y 轴量程和配色；正式版仍使用 Original，不增加用户选项。实际 ANSI 可直接在终端查看，PNG 由捕获的 ANSI 字符格按所选字体排版，只是可复现预览，不宣称是任一原生终端的像素截图。

「当前订阅」沿用订阅页卡片的正文布局。名称下方左侧显示描述，留空时回退到已脱敏域名或文件类型，右侧显示更新时间。下方按已有数据展示剩余量与总量、到期信息和剩余额度进度条。空间不足时优先保留流量数值。概览在名称下方按需插入「尚未应用」「更新未生效」或「等待内核校验」提示。未选用订阅时显示「未使用订阅」。

网络设置按行列出终端代理和虚拟网卡。两行的名称和状态开关各自左对齐，「配置」入口靠右。卡片较窄时，名称独占一行，下一行左侧显示状态、右侧显示「配置」。若两者仍放不下，「配置」移至状态下一行。终端代理区分首次设置、待激活、请求待同步和当前 Shell 已应用，待激活时在该项下方提供「激活命令」。TUN 保存策略与运行观测不一致时，运行状态紧跟在虚拟网卡项下方。错误说明随所属项目显示。普通用户仍可打开 TUN 设置查看权限说明。

每组的配置弹窗以整个终端为中心，四周保留背景。窄屏正文可滚动，操作按钮固定，Esc 取消并将焦点还给该组的「配置」按钮。终端设置显示 Shell、本机代理地址与可编辑的混合端口。TUN 设置显示运行状态和预设参数，复选框编辑随内核启动的策略。

宽屏下「网站测试」居左，「IP 信息」居右。单列页面先展示网站测试，再展示 IP 信息。默认站点是 GitHub、Google 和 YouTube。「管理网站」可以添加自己的站点，也能移除列表中的任意站点。站点列表按当前实例保存。站点按可用宽度排成一至三列，点击站点名称或用键盘选中后按 Enter 可单独测试。当前页排满后可以翻页，右上角的 ⚡︎ 按钮测试所有页面的站点。首次显示「未测试」。完成后，站点名称下方显示访问结果，有 HTTP 响应时还会显示响应耗时。

IP 信息按两行排列。第一行是出口 IP 和位置，第二行是服务商和 ASN。概览中的出口 IP 与远程订阅来源使用同一强调色。首次打开概览且本地代理可用时，卡片自动查询出口 IP。切换订阅、路由模式或节点后，概览会自动查询新的出口。标题右侧显示距上次成功查询的相对时间，如 `刚刚  ↻`、`1 分钟前  ↻`。点击 ↻ 可刷新或重试，查询期间显示 …。实时指标复用应用内共享 WebSocket 会话，没有新增常驻系统服务；各源独立更新，连接数与连接页共享快照。

首次安装区与页头对齐，随窗口可用宽度伸缩。安装详情、展开的日志和错误信息按正文宽度换行。输入框最多 60 格，下载进度条最多 54 格，操作按钮从左侧排列。选择“稍后设置”后，概览只保留内核卡片内一个普通安装按钮；「路由策略」显示安装后可配置模式的提示，未安装时不重复展示内核信息卡片。「当前订阅」标题旁的「订阅 ›」直接进入订阅页，可在该页添加或选用配置。

## 按钮

实际按钮由 `internal/tui/button.go` 的共享渲染函数统一输出。Bubbles 没有对应按钮组件，因此这里只封装外观；页面继续负责操作、取消、禁用检查和鼠标命中。

| 用途 | 表现 |
| --- | --- |
| 主操作 | `primaryButtonBackground` 蓝底、`primaryButtonForeground` 深色文字、加粗 |
| 次操作 | 深色主题使用 `#414C57` 底色和正文色，悬停时底色提亮到 `#4F5F6D`。下拉框触发按钮使用同一配色 |
| 文字操作 | 沿用所在容器背景，使用 `accent` 文字，悬停时加下划线。深色主题中已选节点卡片的「进入 →」使用浅蓝 `#B8CFEC` |
| 纯图标操作 | 悬停时，图标使用正文色 `text`，图标和两侧留白使用 `buttonHoverBackground`。ANSI16 与 `NO_COLOR` 悬停时在原位显示 `[图标]`。键盘焦点显示左侧的 `›` |
| 危险操作入口 | `buttonDangerForeground` 文字、中性表面；悬停使用 `buttonDangerHoverBackground` |
| 最终危险确认 | `errorColor` 底色、深色文字、加粗 |
| 已选择项 | `buttonSelectedBackground`、正文色与加粗；悬停使用 `buttonSelectedHoverBackground`，不添加勾号 |

按钮左侧固定预留两列；键盘焦点显示橙色 ` ›`，与前一个按钮色块相隔一格，紧邻当前色块。相邻按钮不再叠加额外间距。切换焦点、悬停、选择或颜色能力时，标签、后续按钮和命中区位置不变。彩色按钮两侧各留一列空白；ANSI16 与 `NO_COLOR` 使用同宽的 `[标签]`，已选项改用 `<标签>`，不依赖颜色或 SGR 装饰。文字操作继续依靠文字及焦点标记。

`buttonOptions.Width` 表示不含焦点槽及两侧内边距的最小正文字符格宽度，标签在其中居中。路由和语言等选项组由调用方按最长标签统一宽度，正文至少六格；`Aa / ab / .*` 等短筛选开关保留自然宽度，避免窄屏挤掉清空入口。窄屏整颗按钮换行，绘制和命中区共用实际宽度。按钮保持单行，不添加上下整行内边距。概览、设置与代理页的路由选择统一表示保存的目标模式，运行中模式不同或未知时单独说明。

启停按钮使用「启动」「停止」等明确动作文字。路由模式等已选状态不复用主操作蓝底。执行中的普通按钮使用次要文字，禁用按钮使用禁用色，均不生成可操作命中区；已选项保留底色和正文，避免当前选择消失。现有进度与 spinner 继续表达任务状态，可取消任务保留取消入口，等待取消清理时禁止再次触发。

配置删除确认默认聚焦取消；输入名称后需明确确认，名称匹配校验继续保留。普通动作菜单用独立的橙色箭头标记焦点，危险项文字为红色。

设置项、日志筛选、代理组排序和删除配置时的接替者共用单选下拉框。收起时，控件显示当前值和 `▾`。展开后箭头变为 `▴`，焦点移入菜单。行尾的 `✓` 标记已选值，整行底色标记待确认的选项。Mist 浅色主题在 16 色终端额外显示行首 `›`。无色终端把 `›` 从设置行移到候选行，收起菜单后移回设置行。弹层与控件沿同一侧对齐，优先向下展开，下方空间不足时可向上展开，正文保持原位。Enter 或点击选项确认，Esc、Tab 或点击外部取消。

收起的控件保持紧凑。展开后，菜单会利用终端宽度显示长名称。若一行仍放不下，每个候选在列表中各占一行，菜单另用几行显示光标所在项的完整名称。需要翻页时，可按 PgUp、PgDn 或在名称区域使用滚轮。方向键始终用于切换候选。

## 共享输入框

所有可编辑输入由 `internal/tui/input_field.go` 包装 Charm Bubbles textinput：统一三行圆角细描边，文字位于中间一行，左右各一格内边距；框内背景继承页面、卡片或弹窗，不额外填深色。普通输入和搜索最大 60 列，配置 URL / 路径导入最多 72 列；外部留白由布局负责，短窗口压缩。普通边框使用 `border`，悬停提亮，编辑时使用 `accent`，校验失败使用 `errorColor`。新建配置、安装向导与端口窗口采用可滚动正文或压缩标题，当前输入框完整可见，保存、取消及结果提示保留在固定区域。

框内不显示 `>` 或 `/` 前缀，搜索快捷键保留在页脚；整个输入框可点击聚焦。非空时显示普通字重的单格小写 `x`；悬停时只提亮文字、键盘聚焦保留 `›`，不添加下划线；清空后回到输入并保留匹配选项；空内容隐藏清除图标及其分隔线，但仍预留相同空间，避免选项和编辑区跳动。过窄时优先保留编辑区域。清空复用各页面现有编辑处理，清除过期校验、路径补全或计划，不提交表单。

搜索控件整体位于框内右侧，顺序为文字、`x`、细竖分隔线、`Aa ab .*`；清除位于图标组的第一项，使用两列固定槽和紧凑分隔。每个匹配选项使用一格状态槽与两格标签，三项共九列，标签之间只留一格。没有尾部选项的普通输入框中，`x` 与右边框之间只留一格。选中只改变文字为 `accent` 并加粗，`ab` 始终带下划线，鼠标悬停只提亮文字，不给 `Aa` 或 `.*` 添加下划线；焦点使用 `›`，ANSI16 / NO_COLOR 使用 `*` 区分选中，同时选中并聚焦时显示 `+`，各状态保持相同几何位置。规则与日志搜索共用这组匹配选项；不能保留八列编辑空间时匹配选项移到下一行并居右，`x` 仍留在框内右侧，此时不绘制跨行分隔线。日志级别、连接排序等页面控件位于搜索框外。日志去掉搜索框下的常驻摘要，只有搜索或级别筛选生效时才在框外显示匹配比例；正则错误以输入框红边和正文空态提示呈现，不额外占用工具栏行；底栏显示当前可用的按键。

编辑、验证、粘贴、隐藏输入和补全继续由 Bubbles 提供。所有输入关闭虚拟块光标，使用终端真实的闪烁竖线；失焦、弹层遮挡或输入框裁切不完整时隐藏。Bubbles 2.2.1 的真实光标位置按绝对 rune 计数，未覆盖中文显示列与水平滚动偏移，因此在副本上测量其静态虚拟渲染的可见列，再定位真实光标；测量标记不会输出到屏幕。框的命中区域携带实际编辑宽度，窗口缩放保留逻辑位置，水平滚动、中文和弹窗裁剪采用相同坐标。

## 验证与页面预览

日常检查仍为 `make check`、`make race`、`make build`，不会创建虚拟机或安装服务。模型检查覆盖未配置/运行中首页、侧边栏选中/焦点/悬停、Core/Version/Confirm、输入错误、网络独立测试结果、下载、取消清理禁用态及成功/失败结果。尺寸覆盖 160×45、120×32、80×24、60×20、120×18 及极小窗口；每种状态检查 True Color、ANSI256、ANSI16 和无色输出，保持原断点。

只验证真实终端交互与色彩输出，可以在 macOS 或 Linux 对已构建二进制运行：

```sh
python3 scripts/theme-pty.py --binary "$(pwd)/bin/lazyclash" \
  --output .test-artifacts/mariana/pty
```

此入口使用 Python 标准库和已有 VT 当前屏幕还原器，分别启动真彩、256 色和 `NO_COLOR` 会话。每个会话使用独立临时 home 和随机服务名称；验证首页、网络草稿、焦点、缩放和返回，不查询版本、不安装内核或服务。检查输出没有 OSC10/11 颜色设置；256 色不含 RGB，无色模式不含非 reset 的 SGR。它不能证明所有终端模拟器的实际 RGB 显示一致。

导出实际 Go View 并用真实等宽字体排版为单页面 PNG：

```sh
# 使用已安装 Pillow 的 Python；默认查找 Menlo 或 DejaVu Sans Mono。
python3 scripts/theme-preview.py .test-artifacts/mariana
# 其他环境可显式指定等宽 TTF/TTC：
python3 scripts/theme-preview.py .test-artifacts/mariana --font /path/to/monospace.ttf
```

这些预览是 **模型 fixture + 实际 ANSI View + 真实字体** 的排版检查，不是运行中 Mihomo、原生终端截图或服务实测。每张 PNG 对应独立页面/状态；下载数字、运行数据属于明确的模型样本。没有使用生成式效果图。已有来源/代理选项使用左右循环选择控件，本次没有新增独立下拉组件。


## 终端色彩能力与备用配色

Bubble Tea v2 在启动时通过当前输出终端、环境变量、terminfo 及适用时的 tmux 信息检测色彩能力，并发送 `ColorProfileMsg`。LazyClash 在该消息到达前用当前环境给出初值，随后按检测结果重绘；操作步骤、焦点、输入和安装任务均不重置。没有按操作系统选择色彩模式，也没有无条件强制真彩色。

Termius 会话如果报告 `TERM_PROGRAM=Termius` 和 `TERM=xterm-256color`，即使缺少 `COLORTERM`，直接运行 `lazyclash` 也会使用真彩色。这项识别只在当前 TUI 内生效，并尊重已有的 `COLORTERM`、`NO_COLOR` 以及 tmux 和 GNU Screen 的能力检测。

如果 SSH 等连接没有传递终端标识，LazyClash 会按检测到的能力选择配色。只声明 256 色时使用下表中的备用配色；已知终端支持真彩色时，也可为单次进程声明 `COLORTERM=truecolor`。程序不会主动发送 RGB/Tc 查询，部分终端可能错误处理该查询并破坏输出。

下面的数字分别是标准 xterm 256 色索引和 ANSI 16 色索引，属于 C 类终端适配。256 色表使用 16 以上的固定索引，避免依赖用户自定义的前十六色；16 色表不可避免地受终端主题影响。低色模式合并部分背景层次，继续依靠边框、文字和非颜色的当前项/焦点标记区分状态。

`NO_COLOR` 采用非空即禁用颜色的语义，迟到的真彩色能力消息也不能覆盖这个选择。无颜色模式移除颜色和装饰，保留原有文字、边框、当前步骤方括号、`›` 焦点标记与键盘操作。主题只输出应用字符单元的 SGR 样式，不写 Shell 配置或终端调色板；`tea.View` 的终端默认前景/背景字段保持为空，避免通过 OSC10/11 改变终端默认颜色。

`internal/tui/theme_profile_test.go` 检查 True Color 与 ANSI256 下正文、说明、选区、按钮、错误、焦点的实际配对均达到 4.5:1 目标，并检查无颜色、低色模式和窗口缩放期间的内容、布局、任务与焦点保留。这些自动检查不代表已在所有终端模拟器上观察通过。

终端代理独立展示安装、待激活、请求同步与当前 Shell 已应用状态；直接运行二进制时，开启开关会自动补装当前 Shell 的集成。待激活时提供查看 source 命令的入口，退出后的一次性提示由 CLI 在终端恢复后输出。
