# 规则查看

在 TUI 中按 `5` 或选择侧栏的 Rules，查看当前 Mihomo 加载的规则。列表来自控制 API，保留原始匹配顺序和位置；不会用磁盘上的订阅或旧列表代替当前结果。

这里显示的是内核规则列表。Rule 模式按规则顺序匹配；Direct、Global 模式不会因为打开此页而切换为 Rule 模式。页面不提供规则编辑、启用/禁用或配置覆盖操作。

## 布局与筛选

规则采用双行列表：左侧序号独立对齐，第一行突出匹配条件，第二行显示规则类型与目标策略。长条件截断后可打开详情查看完整内容；禁用状态保留在第二行。`MATCH` 在列表中显示「所有剩余流量」，详情仍显示内核返回的空条件。

筛选栏固定在列表上方，滚动规则时仍可操作。宽窗口把输入与选项放在同一行，窄窗口拆为两行；极短窗口将筛选栏并入可滚动正文。摘要显示匹配数与总数，规则保持内核原始顺序，筛选不改变优先级。

- `Aa` / `Alt+C`：区分大小写，默认关闭。
- `ab` / `Alt+W`：整词匹配；Unicode 字母、数字及下划线视为词内字符。
- `.*` / `Alt+R`：正则表达式，默认关闭。无效表达式会显示错误并隐藏结果，修正后立即恢复。
- `×`：清空筛选文字，保留匹配选项并返回输入框。

三个匹配选项可组合使用，对类型、条件、目标、显示序号（如 `#1`）和 API 索引（如 `index:0`）分别匹配，不跨字段拼接。整词模式也对正则匹配结果检查词边界。鼠标悬浮或键盘聚焦选项时，摘要显示该选项说明。

## 操作

- `/` 或点击筛选框：输入筛选条件，默认按大小写不敏感的字面子串匹配。
- `Enter`：结束搜索并选中匹配项，再按一次查看详情。
- `↑/↓` 或 `j/k`：选择规则；长列表自动保持当前选中项可见。
- `Tab / Shift+Tab`：切换焦点；输入中按 Tab 可到匹配选项。鼠标点击规则任一内容行可打开详情；滚轮、`PgUp/PgDn` 可滚动列表。
- `Esc`：退出搜索或从详情返回列表；`q` 退出应用，搜索输入中的 `q` 和数字正常输入。
- `g` / `Ctrl+R` 或 Refresh / Retry：重新读取。`r` 保留原有的服务重启含义。

页面顺序与快捷键统一为 `1 Overview`、`2 Proxies`、`3 Profiles`、`4 Connections`、`5 Rules`、`6 Logs`、`7 Settings`。窄窗口通过 Menu 导航，详情中的长规则条件和中文内容会换行。窗口缩放只影响布局，不重置搜索或重新发起请求。

## 数据与状态

显示位置、类型、匹配条件和目标；详情保留内核返回的原始 index。`MATCH` 的空条件是合法值，不补造匹配条件。记录数为 `-1` 时表示不适用，不能显示成零；其他非负值如实展示。内核提供可选统计时，可查看禁用状态及命中/未命中次数；没有这些字段时不伪造统计。

规则集提供器保持内核返回的引用，不在此页展开或下载规则文件。内核命中统计的生命周期由 Mihomo 决定，lazyclash 不额外落盘。

页面可见时首次异步加载，之后每轮结束五秒再检查一次，避免每秒请求较大的规则列表。离开页面、打开向导、执行操作或退出会取消请求；迟到响应不会覆盖新状态。查询前后检查服务归属、状态、进程和安装身份，跨停止或重启的旧结果会丢弃。

未安装、停止、正在加载、API 不可用、有效空列表和搜索无匹配分别展示。失败时可重试，旧规则不会继续标为当前可用。

## CLI

```sh
lazyclash rules
```

输出按内核顺序排列的 JSON 数组。有效空列表输出 `[]`；内核未安装、未运行或查询失败时返回错误和非零退出码。CLI 和 TUI 使用同一个应用用例和 API 客户端，均只执行读取，不修改配置或启动服务。
