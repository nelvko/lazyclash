# TUI 模态对话框

模态对话框（modal dialog）打开后独占当前页面的输入。遮罩层（backdrop）是对话框后面变暗的背景。

对话框共用 `internal/tui/modal_surface.go` 中的 `modalSurface`。底色、外框、水平留白、分隔线和控件的屏幕坐标由组件统一处理。每种对话框负责自己的内容、焦点、滚动和提交。

带遮罩的居中对话框在真彩与 256 色终端用底色区分层次。16 色与无色终端的浮动对话框在外侧留白处显示细框，全屏时省去外框。单条连接详情使用同一组件的带框样式，背景保留原亮度。

## 操作按钮顺序

页面和弹窗中，同一组按钮都按操作顺序排列。取消、返回、稍后设置等退出操作放在左侧，测试连接、继续编辑等辅助操作排在中间，确认、保存、重试等主操作放在右侧。窄屏换行时保持从左到右、从上到下的阅读顺序。Tab 沿显示顺序前进，Shift+Tab 反向移动。

危险操作的确认框默认选中「取消」，仅提供「返回」或「稍后设置」时选中对应的安全退出项。编辑器恢复弹窗里的「放弃草稿」会删除工作副本，因此打开时选中「继续编辑」。直接按 Enter 可保留草稿。

## 预览入口

先用 120×32 或更大的终端查看居中效果。缩到 80×24 可以对比集合和内核向导的全屏布局。使用 `NO_COLOR=1 lazyclash` 可查看无色样式。

| 对话框 | 如何打开 |
| --- | --- |
| 新建订阅 | 订阅 → 新建。粘贴远程 URL 后，按 Enter 可直接创建，按 Tab 可填写 User-Agent、名称和描述。 |
| 订阅设置 | 在订阅页聚焦一张卡片后按 Enter，或点卡片的 ⋯ → 设置…。 |
| 导入覆写 | 订阅设置 → 导入覆写…。 |
| 删除订阅 | 订阅卡片 ⋯ → 删除…。选中当前使用的订阅时，还能查看删除后使用的配置或直连选项。 |
| 编辑器恢复 | 在测试订阅的 ⋯ 菜单选「编辑配置…」或「编辑覆写…」。如果使用 Vim，可直接输入 `:cq` 并回车，让编辑器以错误状态退出，查看「继续编辑」「重试保存」等操作。 |
| 导入配置 | 在概览页浏览状态按 `a`。订阅页的同一按键会聚焦页内来源输入框。 |
| 编辑器 | 点击设置 → 常规中的「编辑器」一行，或聚焦该行后按 Enter。 |
| 终端代理设置 | 安装 Mihomo 后，概览 → 网络设置 → 终端代理 → 配置。 |
| 终端代理激活命令 | 终端代理显示「待激活」时，点同一分区的「激活命令」。 |
| 虚拟网卡设置 | 安装 Mihomo 后，概览 → 网络设置 → 虚拟网卡 → 配置。普通用户实例可查看权限说明。 |
| 启用主机 TUN 确认 | 在已安装内核、支持 TUN 且 TUN 已关闭的 root 系统实例中，点「虚拟网卡」的关闭状态开关。点「取消」可退出预览。 |
| 运行设置 | 安装 Mihomo 后，设置 → 服务与端口 → 本地端口 / 控制 API → 编辑。 |
| 管理 Mihomo | 安装后点击「设置 → 内核管理 → 已安装版本」。在概览按 `b` 可预览同一向导的本地可执行文件输入步骤。首次安装的引导显示在概览页内。 |
| 检查内核更新 | 安装后点击「设置 → 内核管理 → 检查更新」。查看结果后按 Esc 回到卡片，有新正式版时可确认升级。 |
| 下载方式 | 在概览页浏览状态按 `n`。 |
| 代理集合 | 点代理页页头的「代理集合」。 |
| 规则集合 | 点规则页页头的「规则集合」。内核运行时可查看已加载的集合。 |
| 关闭全部连接确认 | 连接 → 活跃，有活动连接时点页头「关闭全部」。选「取消」退出预览。 |
| 单条连接详情 | 在「活跃」或「已关闭」列表聚焦一条连接后按 Enter。宽屏显示在右下角，窄屏居中。 |

订阅卡片的 ⋯ 操作菜单与设置页的语言下拉菜单贴近触发控件并保留边线。右上角的通知卡使用独立样式，有通知时按 Ctrl+N 可展开。
