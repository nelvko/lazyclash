# TUI 通知

全局 Toast 固定从页头右侧开始，不随输入框向下移动、不改变正文高度或滚动位置。宽屏最多展开两条，旧消息在上、新消息在下；窄屏或矮屏最多一条，采用无边框紧凑布局。输入框紧接顶栏时，短通知可在标题右侧以无边框样式显示。空间不足时，单条结果保留一行正文和关闭按钮，正文被截断时出现详情入口。多条折叠时显示类型和数量。

## 哪些结果会弹出

| 操作 | 完成后的反馈 |
| --- | --- |
| 选用订阅 | 切换并确认成功后只显示“已选用订阅「订阅名」”。运行中和已停止的内核使用相同文案。重复点击当前订阅保持静默。 |
| 停用订阅 | 提示已停用的订阅名、当前未选用订阅以及内核状态。 |
| 添加、导入、创建、删除或手动更新订阅 | 弹出目标及结果。删除当前项同时交代接替项，批量更新只发一条汇总。新添加的订阅仍需手动选用。 |
| 重启内核、修改终端代理 | 弹出结果。终端代理告知退出 TUI 后的同步或手动激活步骤。 |
| 启停内核、切换 TUN、安装或升级、应用端口 | 概览开关、向导和端口结果页提供就地反馈。可以离开操作页的任务，在其他页面完成时弹出结果。 |
| 选节点、切模式、保存偏好 | 正常结果由控件展示。无法确认所选节点、模式，或保存发生异常时提示原因。 |
| 测速、更新集合、关闭连接 | 进度、延迟、单项失败和关闭请求在对应页面展示；关闭请求由后续连接观测确认。 |
| 浏览、搜索、筛选、取消未提交的输入、正常轮询 | 不生成通知记录。 |

普通任务持续 500 毫秒后才弹出进度。快速操作直接给出最终反馈，慢速操作用同一条记录更新结果。

底部只保留终端最后一行的按键提示，旧状态栏的空行归还正文。正文、滚动指示和侧栏可使用倒数第二行；紧凑导航展开时同步覆盖这一行并阻止点击穿透。

每张卡直接显示结果，普通成功只有正文和关闭按钮。错误正文交代出错的操作和原因，警告带有文字标记，无色终端也能辨认。出现独立诊断或当前卡片放不下全文时才显示详情。打开后可滚动阅读完整正文和额外说明。

## 操作与保留

- 同一操作的进度和结果更新同一条通知。一次安装的版本解析、预检和安装共享一条记录。不同操作分别保存，即使错误文字相同也不合并、不添加重复次数。
- 重试通过操作和资源标识关联原失败；资源标识内部使用摘要，来源 URL 或凭据不作为展示上下文。
- 成功提示展示 3 秒，普通信息展示 4 秒。错误、保存失败、实际状态未确认和需要手动激活的警告会保留，直到关闭或同一操作重试后更新结果。静默记录不占浮层或溢出计数。打开弹窗、帮助、菜单或展开通知时，暂停自动关闭计时。需要展示的通知在溢出区也暂停计时，正文完整可见后从剩余时长继续；新的结果重新计时，旧定时器不影响新结果。
- 关闭进行中通知只隐藏它，不取消任务；最终结果仍可以出现。取消任务保留原有 Esc/Ctrl+C 行为，普通取消是信息，伴随清理或恢复失败时仍是错误。
- 后台 runtime、rules 和 logs 采样错误保留在各自页面，不为每次轮询创建全局 Toast。
- 操作后的状态回读失败时，页面保留配置库等已有数据，但运行状态显示未知，不把上次观察到的实际模式和节点作为当前事实。后续有效状态观察恢复展示。无关成功不会删除其他操作的错误通知。
- 安装或端口应用弹窗中的恢复失败、最终状态回读失败同时保留一条全局错误，关闭弹窗后仍可查看；弹窗内的普通校验不生成全局通知。重试成功后更新原错误。端口已经提交但回读失败时仍明确保留“已应用”的结果，运行状态显示未知。

## 列表、详情与输入

浏览页面时，有通知才响应 `Ctrl+N`。有多条通知时，每条在右上角各占一张卡，操作按钮只作用于本条通知。按下快捷键或点击“另有 N 条 · 展开”可以滚动浏览全部卡片，当前页面仍然可见。点击“详情”（空间较小时为“⋯”）可在右上角显示完整说明。

- 在列表中用 `Tab` 或方向键选择操作，`Enter` 执行，`x` 关闭选中的通知。列表和长详情都支持鼠标滚轮与 `PgUp/PgDn`，关闭进度通知和取消任务是两个独立操作。
- 从列表进入详情，`Esc` 回到原列表位置。从页面直接打开详情，`Esc` 回到页面。再次按 `Ctrl+N`、点击外侧或移除最后一条记录时，直接收起并恢复原焦点。外侧点击只负责收起。
- 输入框、菜单和对话框优先处理各自的按键。通知出现时不抢焦点，查看过程中暂停计时，收起后从剩余时间继续。

订阅地址为空、格式不正确等局部校验紧贴 Profiles 输入框显示，保留输入，修改或离页后清除。来源和地址编辑弹窗在提交前校验，错误继续留在弹窗中。下载、校验和保存等异步失败进入全局通知，切换页面后仍可查看原因。不会为了自动关闭 Toast 而给所有页面添加重复错误面板。

验证入口见 [verification.md](verification.md)，真实终端场景由 `scripts/theme-pty.py` 的通知检查覆盖。
