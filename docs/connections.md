# 连接页面

Connections 参考 Clash Verge、CFW 和 FlClash 的连接检查界面，使用完整正文宽度。页头右侧依次显示累计下载、累计上传、暂停/继续和“关闭全部”；不展示内存。两项累计量分别来自 `/connections` 的 `downloadTotal` 和 `uploadTotal`，包含已经结束的连接，不由列表行求和，也不随搜索或活跃/已关闭切换改变。字节数自动换算为 B、KiB、MiB 等单位，窄屏使用 ↓ / ↑ 简写及动作图标，不可用时显示 `--`。

搜索框沿用规则页的简洁边框，只保留 Bubbles 输入与清空动作。活跃/已关闭标签在搜索框左侧，数量表示当前展示快照的活跃数与本地保留的关闭记录数；输入框右侧仅在有非空筛选条件时显示“匹配数 / 总数”，默认隐藏重复总数，再显示框外排序按钮。计数隐藏时仍按最大比例保留原有占位，排序按最长文案预留宽度，输入、清空和切换排序不改变搜索框的位置与宽度。连接与日志复用同一工具栏布局：空间不足时标签和排序相邻放在搜索框上方，完整搜索框放在下一行，计数必要时再换行；Tab / Shift+Tab 沿可见控件的阅读顺序移动。工具栏固定，正常实时状态直接接列表；暂停、历史范围及不可用状态保留说明。极短窗口沿用工具栏进入正文滚动的退化方式。

## 已关闭记录的范围

Mihomo 接口只返回活跃连接数组，没有已关闭数量、历史查询参数或关闭连接的最终流量。与 Verge Rev 一样，界面通过比较同一内核连续有效的连接快照，将消失的连接留存在内存；本次运行最多保留最近 500 条，可以切换、搜索和查看详情。流量为最后一次观测值，结束时间为首次发现连接消失的时间，历史速度显示 `--`，时长不再增长。

记录不会写入磁盘，无法补查启动前的连接，短于采样间隔或断线期间的连接可能遗漏。错误、无效或不可用快照只中断比较，不把整张列表误记为关闭；已有历史仍可离线查看。确认内核身份或累计计数器重置后清空旧历史，避免混用不同实例。历史详情始终只读，同 ID 重现也不会把历史关闭动作转到新连接。暂停同时冻结标签计数、列表和页头总量，后台仍继续收集。

字段定义参见 [Mihomo API 文档](https://wiki.metacubex.one/api/#connections)；客户端保留历史的参考见 [Verge Rev 实现](https://github.com/clash-verge-rev/clash-verge-rev/blob/dev/src/hooks/use-connection-data.ts)。

正文至少 85 列时复用 Charm Bubbles table，120 列终端即可显示目标、协议、代理链、双向速度和时长；至少 125 列增加进程和匹配规则，至少 155 列增加单条累计下载/上传量。剩余宽度优先分配给目标地址；代理链过长时先省略中间策略组，保留最终出口，出口名称自身超宽时才截断名称。速度、累计量与时长连同表头右对齐。更窄时使用双行列表，优先显示目标、协议、速度和进程；完整字段在详情内查看。Bubbles textinput 负责搜索编辑和水平滚动；页面沿用 dashboard 的滚动、键盘焦点和鼠标命中，仅渲染可见连接。

- `v` 切换活跃/已关闭；也可点击标签或用 Tab 聚焦后 Enter 选择。切换保留搜索条件。
- `/` 搜索：不区分大小写，匹配域名、IP、端口、协议、进程、路径、规则、代理链和连接 ID。`×` 清空。Enter/Esc 完成输入，Tab/Shift+Tab 移动到相邻控件。
- `s` 循环排序：最新、下载速度、上传速度、累计下载、累计上传、时长。除时长从长到短外，其余数值从大到小；同值按连接 ID 稳定排序。排序和实时更新保持选中 ID。
- `p` 或页头暂停/继续：固定本页列表、速率、累计量和时长，后台监控仍继续。恢复时立即显示最新观测。详情、关闭确认和操作进行中禁用暂停；内核停止、API 不可用、内核身份改变或累计计数器重置时，丢弃旧快照。
- ↑↓/j/k 选择，Home/End 跳到首尾，PgUp/PgDn 按可见行数翻页。Enter 或点击任一行打开详情，Esc/← 返回并保留筛选与列表位置。
- `x` 审阅关闭单条活跃连接，默认选择取消，`y` 确认。详情和关闭校验始终使用实时状态；暂停期间已经结束的连接不能关闭其他行。

底栏随焦点与状态显示当前可用操作：搜索输入只提示结束输入，列表暂停后提示继续；空列表不提示详情或关闭，已关闭记录及暂停快照中已经结束的连接不提示关闭。详情不再显示仅对列表有效的切换、排序和暂停键。关闭确认时，Enter 明确对应当前聚焦的取消或确认关闭按钮。

页头“关闭全部”先展示确认，默认取消。确认后一次性关闭 Mihomo 的全部活动连接，包括筛选结果之外、暂停快照之外及确认期间新建立的连接；执行时恢复实时画面并保留搜索条件。无活动连接、数据不可用或操作进行中时不可执行。连接页不再提供手动刷新按钮或 `g` / `Ctrl+R` 刷新快捷键，数据由共享实时会话持续更新。

速率用相同连接连续两次成功观测的累计字节差除以实际观测间隔计算。首次采样、计数器回退、内核切换、连接 ID 重新使用或观测中断时显示 `--`；已知空闲连接显示 `0 B/s`。速率仅供展示，不参与内核累计量计算。

验证入口：

```sh
go test ./internal/tui -run 'TestConnection|TestLiveConnections' -count=1
go test -race ./internal/tui -run 'TestConnection|TestLiveConnections|TestRuntime' -count=1
go test -c ./internal/tui -o bin/connections-tui.test
python3 scripts/connections-pty.py --binary bin/connections-tui.test \
  --output .test-artifacts/connections-redesign/pty \
  --profile truecolor --profile 256 --profile no-color --png
```

PTY 使用显式启用的隔离内存后端，不访问真实 Mihomo 或操作系统服务。PNG 根据真实 PTY 字符格与颜色重绘。
