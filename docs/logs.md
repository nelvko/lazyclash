# 实时日志查看

TUI 中按 `6` 或选择 Logs，查看当前 Mihomo 通过认证控制 API 发出的日志。CLI 和 TUI 直接使用同一个 `app.StreamLogs` 用例，不启动自身 CLI，也不修改服务、订阅或日志级别。

这是一段**当前 TUI 会话的实时观察**。已安装且内核运行时，TUI 初始状态加载后开始采集，无需先打开日志页；打开日志页可查看本会话已保留的记录。连接建立前的事件没有历史回放。默认配置日志级别较高、内核空闲时可能没有新事件；空白列表表示尚未收到事件，不代表发生错误。首次打开日志页也会尝试连接并诊断不可用原因。

协议核对自 Mihomo [v1.19.33 的 `getLogs`](https://github.com/MetaCubeX/mihomo/blob/v1.19.33/hub/route/server.go)：使用普通 HTTP `/logs?level=info`，每行一个 `{type,payload}` JSON 事件；不使用 structured 格式，也不更改内核全局日志级别。上游自身的有限队列在压力下可能丢弃事件，因此这是实时诊断视图，不承诺完整的审计记录。

采集连接属于 TUI 会话，切页、查看帮助、打开表单或执行普通任务均不断开连接。真实断流后按 1、2、4、8、16、30 秒的退避间隔自动重试，之后最多每 30 秒一次；收到事件后重置退避。重连后的首条日志到达时，在状态区提示中断期间无历史补采，不向日志列表插入提示记录，不影响条数或筛选结果。退出 TUI 会关闭连接，进程不会在后台守护或继续采集。

## TUI 操作

- `f`、列表聚焦时的 `Space` 或 Pause display/Resume display：暂停或恢复**显示**。暂停显示时画面保持当前内容，后台继续采集并维护有界缓存；恢复显示时回到当前缓存的最新记录，不重连。
- `↑/↓`、`PgUp/PgDn`、`Home` 或鼠标滚轮：浏览保留的记录并停止自动跟随，采集继续进行，新事件不会把视口拉回底端。阅读期间的 `+N` 表示新收到的事件总数，包含被当前筛选隐藏的事件，计数最多为 200。
- `End` 或底部 Latest：恢复显示，回到最新记录并恢复自动跟随，不重连。
- `/` 或固定搜索框：搜索已保留的日志级别或脱敏正文，不暂停采集。输入中的数字与 `q` 正常作为文本，不会跳页或退出；`Enter` / `Esc` 完成输入。搜索框旁的 `×` 只清空搜索文本。
- `l` 或级别控件：循环切换全部、Info、Warn、Error 的本地显示筛选，不改变采集请求或内核的全局日志级别。
- `v` 或视图控件：切换简洁与详细布局。默认详细布局将时间、级别放在首行，正文完整换行，并用弱分隔线区分记录；简洁布局将一条记录压成一行，超宽正文截断。
- `Ctrl+L` 或页头 Clear：清空当前内存中的日志，保留搜索文本、级别及视图设置，不重连或改变采集状态。
- `g` / `Ctrl+R` 或 Reconnect/Retry：手动重新连接当前内核，无需等待自动重试。
- `?`：查看可滚动帮助。关闭帮助或返回日志页时沿用正在进行的采集连接与保留记录。

固定工具栏复用 Charm Bubbles `textinput`，日志阅读区复用 `viewport`；窗口缩小时工具栏自动换行。页面分别显示等待新事件、跟随最新、阅读保留记录、显示暂停、连接重试或连接恢复，区分“尚未收到日志”与“没有匹配记录”。筛选只影响正文显示，中断与恢复状态独立提示。

实时缓存在内存中保留最近 200 条脱敏记录；暂停显示时另存最多 200 条的独立快照，恢复或清空时释放。单条正文及任务通道均有容量边界；浏览期间也可能因达到上限而淘汰最早记录。时间为 LazyClash 的本机观察时间，Mihomo 默认事件不包含原始时间，界面不补造。颜色配合级别文字区分普通事件、警告和错误；无颜色终端仍可通过级别文字识别。

## CLI

```sh
lazyclash logs
lazyclash logs --lines 100 --duration 5s
```

默认收集最多 200 条新事件或观察 5 秒，达到任一边界即完成并输出 JSON 数组；`--lines` 支持 1–500，`--duration` 大于零且最多 1 分钟。连接正常但窗口内无事件时输出 `[]`；未安装、停止、鉴权失败、无效事件或连接中断返回错误。Ctrl+C 取消会终止流，不把被取消的操作伪装成一次完整观察。

## 数据边界

只连接当前安装所属的本机控制 API，请求前后及流持续期间检查服务归属、安装身份和进程，停止、重启或归属变化会结束旧流。网络读取期间不占用应用锁。

已知控制密钥、完整 URL（包括未知查询参数和私有路径）、常见认证/密码/令牌字段及终端控制序列在进入 CLI/TUI 前处理。原始帧不写入日志文件或 systemd journal；既有服务标准输出策略不因日志页面改变。日志仍可能包含正常的目标主机、地址和进程描述，脱敏不等同于将所有网络活动匿名化。
