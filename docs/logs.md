# 实时日志查看

TUI 中按 `6` 或选择 Logs，查看当前 Mihomo 通过认证控制 API 发出的日志。CLI 和 TUI 直接使用同一个 `app.StreamLogs` 用例，不启动自身 CLI，也不修改服务、订阅或日志级别。

这是一段**当前会话的实时观察**。没有历史回放，打开页面前的事件不会补回。默认配置日志级别较高、内核空闲时可能没有新事件；空白列表表示尚未收到事件，不代表发生错误。停止的内核或不可用的控制 API 会明确显示不可用，可从现有服务入口启动或诊断后重试。

## TUI 操作

- `f` 或 Pause/Resume：暂停或恢复采集。暂停会断开请求；恢复后标记期间没有采集日志，不声称连续完整。
- `↑/↓`、`PgUp/PgDn`：查看已保留的行并暂停自动跟随，视口不会被新事件拉回底端。
- `End`：恢复采集并跟随最新内容。
- `/`：搜索已保留的日志级别或脱敏正文，搜索会暂停采集。输入中的数字与 `q` 正常作为文本，不会跳页或退出。
- `g` / `Ctrl+R` 或 Reconnect/Retry：重新连接当前内核。
- `?`：查看可滚动帮助。离开页面、打开帮助/向导或退出时取消请求；返回后保持已有记录，并明确采集间隙。

列表只在内存中保留最近 200 条脱敏记录，单条正文及任务通道均有容量边界。时间为 LazyClash 的本机观察时间，Mihomo 默认事件不包含原始时间，界面不补造。颜色配合级别文字区分普通事件、警告和错误；窗口缩放只改变可见行数。

## CLI

```sh
lazyclash logs
lazyclash logs --lines 100 --duration 5s
```

默认收集最多 200 条新事件或观察 5 秒，达到任一边界即完成并输出 JSON 数组；`--lines` 支持 1–500，`--duration` 大于零且最多 1 分钟。连接正常但窗口内无事件时输出 `[]`；未安装、停止、鉴权失败、无效事件或连接中断返回错误。Ctrl+C 取消会终止流，不把被取消的操作伪装成一次完整观察。

## 数据边界

只连接当前安装所属的本机控制 API，请求前后及流持续期间检查服务归属、安装身份和进程，停止、重启或归属变化会结束旧流。网络读取期间不占用应用锁。

已知控制密钥、完整 URL（包括未知查询参数和私有路径）、常见认证/密码/令牌字段及终端控制序列在进入 CLI/TUI 前处理。原始帧不写入日志文件或 systemd journal；既有服务标准输出策略不因日志页面改变。日志仍可能包含正常的目标主机、地址和进程描述，脱敏不等同于将所有网络活动匿名化。
