# 实时日志查看

TUI 中按 `6` 或选择 Logs，查看当前 Mihomo 通过认证控制 API 发出的日志。查看日志保持当前服务、订阅及日志级别。

这是一段**当前 TUI 会话的实时观察**。已安装且内核运行时，TUI 初始状态加载后开始采集，无需先打开日志页；打开日志页可查看本会话已保留的记录。连接建立前的事件没有历史回放。默认配置日志级别较高、内核空闲时可能没有新事件；空白列表表示尚未收到事件，不代表发生错误。首次打开日志页也会尝试连接并诊断不可用原因。

协议核对自 Mihomo [v1.19.33 的 `getLogs`](https://github.com/MetaCubeX/mihomo/blob/v1.19.33/hub/route/server.go)：使用普通 HTTP `/logs?level=info`，每行一个 `{type,payload}` JSON 事件；不使用 structured 格式，也不更改内核全局日志级别。上游自身的有限队列在压力下可能丢弃事件，因此这是实时诊断视图，不承诺完整的审计记录。

采集连接属于 TUI 会话，切页、打开表单或执行普通任务时仍持续采集。断流后按 1、2、4、8、16、30 秒的间隔自动重试，之后每 30 秒重试一次。收到事件后重置退避。重连时状态区显示“正在重连”，连接恢复后短暂显示“连接已恢复”。断线期间的日志无法补回。退出 TUI 会关闭采集连接。

## TUI 操作

页头保留 Clear / Pause / Resume（清空 / 暂停 / 恢复），常态不重复显示“实时”。暂停显示时，页头显示“已暂停”，新采集的事件用 `+N` 提示。手动重连仅通过 `Ctrl+R`，不展示重连按钮。

- `f`、列表聚焦时的 `Space` 或 Pause/Resume（暂停/恢复）：暂停或恢复**显示**。暂停时画面保持当前内容，后台继续采集并维护有界缓存；恢复时回到当前缓存的最新记录，不重连。
- `↑/↓`、`PgUp/PgDn`、`Home` 或鼠标滚轮：向上翻离底部时进入历史浏览。新日志到达时保留阅读位置，向下滚回底部恢复自动跟随。阅读期间的 `+N` 表示新收到的事件总数，包含被当前筛选隐藏的事件，计数最多为 200。
- `End` 或底部 Latest：恢复显示，回到最新记录并恢复自动跟随，不重连。
- `/` 或固定搜索框：搜索已保留的日志级别或脱敏正文，不暂停采集。输入中的数字与 `q` 正常作为文本，不会跳页或退出；`Enter` / `Esc` 完成输入。搜索框旁的 `×` 只清空搜索文本。
- `Aa`、下划线 `ab`、`.*` 或 `Alt+C` / `Alt+W` / `Alt+R`：分别切换区分大小写、整词匹配与正则表达式，行为与规则页一致。默认不区分大小写、按普通文本匹配；整词边界支持 Unicode 字母和数字。搜索和浏览时都可切换，仅筛选当前保留记录，不影响采集。无效正则表达式会以搜索框红色边框与正文空态提示标出，修正后恢复匹配。
- 按 `l` 或点击级别控件，可在下拉菜单中选择全部、信息、警告或错误。行尾的 `✓` 标记当前筛选。`↑/↓`、`j/k`、`Home/End` 移动游标，`Enter` 确认，`Esc`、`Tab` 或点击菜单外取消。菜单浮在日志上方，选择只影响本地显示。
- `v` 切换自动换行。默认完整显示长日志，续行与正文对齐。关闭换行后每条日志只占一行，超出窗口宽度的部分被截断。再次按 `v` 可读到完整正文。
- `Ctrl+L` 或页头 Clear：清空当前内存中的日志，保留搜索文本、匹配选项、级别及换行设置，不重连或改变采集状态。
- `Ctrl+R`：手动重新连接当前内核，无需等待自动重试。这是日志页唯一的手动重连入口；页面不显示重连按钮。
- 浏览日志时按 `?` 隐藏或显示底部提示栏。在搜索框中可以正常输入问号。

搜索框提示为“搜索日志”，右侧复用规则页的 `Aa`、下划线 `ab` 与 `.*` 匹配选项，并保留清空搜索入口。级别下拉框位于搜索框左侧，筛选计数紧随搜索框。空间不足时，级别下拉框移至搜索框上方，计数按需换行。Tab / Shift+Tab 沿可见控件的阅读顺序移动。匹配选项在极窄窗口下同样自动换行；切换选项不会改变输入框尺寸。

搜索框下不再常驻来源、数量、观察时间或操作提示。输入搜索条件或选择非“全部”级别时，在框外显示“匹配数 / 当前显示记录数”，无筛选时隐藏；未筛选的空列表也不显示“0 / 0 条”。计数与输入分开布局；正则错误在正文空态提示，不再额外占用工具栏一行，连接异常继续按需显示。

底栏提示随输入和焦点更新。搜索时提示结束输入，暂停后提示恢复显示。聚焦匹配选项时提示切换对应模式，聚焦级别控件时提示打开选择菜单。日志正文没有 Enter 操作，不显示此提示；Space 的暂停/恢复提示仅在日志列表聚焦时出现。

固定工具栏复用 Charm Bubbles `textinput`，日志阅读区复用 `viewport`；级别下拉复用公共菜单的选择能力。搜索框保留三行边框，正文紧随工具栏，不为已移除的摘要保留空行。窗口缩小时工具栏自动换行。实时采集已就绪且尚无日志时，页面中央只显示“暂无日志”。自动跟随时底部显示跟随状态。仅在回看或暂停时，右下角显示“最新 ↓”按钮，可点击返回实时日志。有筛选条件且没有匹配记录时，正文提供清除筛选入口。筛选只影响正文显示，中断与恢复状态独立提示。

实时缓存在内存中保留最近 200 条脱敏记录；暂停显示时另存最多 200 条的独立快照，恢复或清空时释放。单条正文及任务通道均有容量边界；浏览期间也可能因达到上限而淘汰最早记录。时间为 LazyClash 的本机观察时间，Mihomo 默认事件不包含原始时间，界面不补造。颜色配合级别文字区分普通事件、警告和错误；无颜色终端仍可通过级别文字识别。


## 数据边界

只连接当前安装所属的本机控制 API，请求前后及流持续期间检查服务归属、安装身份和进程，停止、重启或归属变化会结束旧流。网络读取期间不占用应用锁。

已知控制密钥、完整 URL（包括未知查询参数和私有路径）、常见认证/密码/令牌字段及终端控制序列在进入界面前处理。原始帧不写入日志文件或 systemd journal；既有服务标准输出策略不因日志页面改变。日志仍可能包含正常的目标主机、地址和进程描述，脱敏不等同于将所有网络活动匿名化。
