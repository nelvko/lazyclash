# 代理组与节点

TUI 中按 `2` 或选择 Proxies，浏览当前 Mihomo 控制 API 返回的代理组及成员。分组列表以留白区分组块：相邻组之间空一行，不绘制横向分隔线。组头显示名称、当前最终节点和右对齐的纯数字成员数徽标；自动策略组保留低强调的「自动」标记，折叠箭头放在成员数右侧，名称前只保留键盘焦点标记。正常高度的宽窗口中，组头上下各留一行，整块区域可以点击和悬浮高亮；短窗口使用紧凑组头。完整类型与引用路径在详情中查看。

展开后只保留组头和节点卡片，不重复显示「当前选择」，默认排序也不单独占行。组头与第一排卡片之间空一行；卡片的两行内容上下各留一行，名称与元数据左对齐，延迟和「进入」操作右侧保留两格留白。卡片展示候选项、节点协议、UDP 支持和延迟；引用卡片的第二行内容统一显示「策略组 · 最终节点」，并保留独立的「进入 →」。测速操作放在展开组的标题行，空间不足时换行。只读取与选择有关的元数据，不展示节点服务器、密码或其他原始配置字段。

正文使用全部可用宽度，节点列数随实际内容宽度变化，最多四列；只有一、两个成员或搜索后剩余少量成员时，卡片仍占对应列宽，不拉伸填满整行。卡片保留紧凑的行列间隔。宽屏的模式和搜索控件同行，空间不足时换行。宽窗口允许多个组独立展开，打开另一组不会收起已有组；搜索栏右侧提供「全部收起」。小于 100 列的终端采用「代理组目录 → 组内成员」两级浏览。缩放保留搜索、排序、展开组和操作位置。长名称在列表内截断，详情显示完整名称；不依赖旗帜或颜色识别节点。

组内成员连续滚动，不采用分页。可见范围提示 `1–12 / 48` 表示当前视口内的成员范围与总数；多组展开时按页面中的全部展开成员计算，搜索生效时按筛选后的成员计数。切换排序后仍以成员身份保留焦点。

## 操作

- `Enter`：展开或折叠组。在 Selector 的成员上按 Enter 改选；在自动组成员上查看详情。
- `↑/↓` 或 `j/k`：移动焦点；`Home/End` 到首尾。多列成员中的上下移动保持所在列，滚轮、`PgUp/PgDn` 滚动正文。
- `→` 或 `l`：在多列中先移至同一行右侧的相邻节点；到达右侧边界后，引用组节点可继续进入目标组。在组标题上进入成员。引用组卡片另有「进入 →」入口，可以直接进入；Enter 激活卡片主体仍执行选择或查看详情。
- `Esc`：从详情、引用组或窄窗口成员页逐级返回，再返回应用导航。`←` 或 `h` 在多列中先移至同一行左侧的相邻节点，其余情况执行返回。宽屏进入引用组时保留组列表并就地跳转；窄屏进入独立成员页。返回引用来源时恢复原展开组集合、搜索、焦点与滚动位置。
- `i`：查看成员完整名称、类型、当前选择路径及可用的测试详情。
- `/`：搜索组或节点名称，大小写不敏感。搜索输入中的数字和 `q` 作为文本；Enter 或 Esc 结束输入，清除搜索恢复完整列表。
- `s`：为焦点所在组选择默认顺序、延迟、名称，各组分别保留排序。默认顺序保留内核成员顺序，不额外显示排序行；使用非默认排序时，组头显示对应排序入口。组目录按名称排序，不宣称恢复原配置文件顺序。
- `t` 或组头的「测速」：测试当前组的可测试成员；再次按 `t` 或本组「取消测速」取消本轮，保留已经完成的结果。点击另一组「测速」会取消旧轮并测试目标组；同一时间只运行一组。折叠组或「全部收起」不会取消测速。
- `r`、`g`、`Ctrl+R` 或 Refresh：重新读取当前状态，不发起测速。在 Proxies 正文中，`r` 不再表示重启服务。
- `Tab/Shift+Tab`：在应用导航、页头、页面控件和列表之间移动。列表作为一个焦点组，成员不逐项占用 Tab 停靠点。

节点卡片左侧的选中竖条贯穿卡片全高，表示内核已确认的当前项，`›` 表示键盘焦点，两者独立显示。卡片上下留白也可以点击选择；引用卡片的「进入 →」独立处理浏览操作。切换期间保留原选择，目标项标为切换中；重新读取控制 API 确认后再显示新选择。失败或不能确认时不报告成功。

## 组语义与路由模式

Selector 允许手动改选。URLTest、Fallback 等自动组由内核选择；成员可查看详情，但不能在这里手动应用。LoadBalance 和 Relay 由内核按自身策略处理，不展示虚构的固定单一节点。DIRECT、REJECT 是普通有效候选项，REJECT 不作为界面操作错误标红。

组头摘要优先显示按当前选择解析到的最终节点，例如 `HK 02`，不重复展示完整引用链。详情中的 `默认代理 → 自动选择 → HK 02` 是按代理组当前选择展开的路径，不代表每条连接实际采用的完整链路。负载均衡、Relay 或没有可确定当前项时停止展开；连接的实际链路应在 Connections 中查看。

模式控件显示内核实际模式，并通过共享应用用例修改。Global 模式首先展示 GLOBAL，可继续进入它引用的组；宽屏浏览时将当前引用目标补充显示在同一列表中，窄屏只显示目标组。Rule 模式显示其他代理组，宽屏进入引用组时仍保留普通组列表。Direct 模式提示普通流量直连，组选择继续保留，不因浏览页面自动切换模式。

## 延迟测试

测速使用受管的本机认证控制 API，让 Mihomo 通过指定候选项访问固定测试目标。默认目标为 `https://www.gstatic.com/generate_204`，单次超时为 5 秒。每轮仅测试当前组，最多同时发起 4 项；不是整份配置的全量测试。DIRECT、REJECT、LoadBalance、Relay 以及无法确定单一出站的引用路径不生成虚构延迟。

延迟区分未测试、等待中、测试中、数值、超时、测试失败与不适用；卡片以 `—` 简写不适用状态，详情保留说明。普通节点可显示已有内核历史样本，但其测试目标不可从历史记录确定，详情明确标注。引用组只展示本次会话中记录了选择路径的测试结果；路径变化后恢复为未测试，避免把旧路径的历史延迟附在新选择旁。某个测试目标失败不能证明节点整体离线。

测速进度只在实际发起测试后显示，完成或用户取消后保留两秒提示再收起；空闲或没有可测试节点时不显示 `已测试 0/0`。测速完成只更新结果，不自动重排候选项。需要重新排序时再次选择延迟排序；已有焦点和选择按成员身份保留。离开页面、执行会改变运行状态的操作或退出时取消正在进行的测试，不延续进度提示；迟到结果不会覆盖新一轮。结果保留在当前会话内存，不额外保存至配置或磁盘。

## 不可用状态

未安装、内核停止、API 不可用、没有代理组、有效空组和搜索无匹配分别显示。未安装或停止提供相应安装、启动入口；API 错误保留诊断与刷新入口。旧数据不会继续作为可操作的实时列表。

CLI 的 `nodes`、`select` 继续使用共享应用与 API 用例。TUI 不启动 CLI 子进程，也不改变服务安装或 TUN 的权限边界。
